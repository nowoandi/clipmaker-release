---

Сними одну партию видео по скиллу clip-shoot.

1. Выставь `$env:CLIP_PROJECT = "<папка проекта>"` ($ARGUMENTS; если пусто — спроси у Админа).
2. Прогони `python "${CLAUDE_PLUGIN_ROOT}/scripts/gate_preflight.py" --project "<папка>"`. Exit 2 — читай stderr и чини данные (план, retries, реестр), стоп не обходить.
3. Запусти партию по скиллу `${CLAUDE_PLUGIN_ROOT}/skills/clip-shoot/SKILL.md`: 4–5 отправок (R11), одна попытка на сцену (R09), запуск процессов по R22.
4. После партии — `python "${CLAUDE_PLUGIN_ROOT}/scripts/clip_status.py" --project "<папка>"` и доклад Админу: что снялось, что нет, сколько отправок ушло.

Следующая партия — только через новый предполёт: маркер сгорает при запуске съёмочной команды.
