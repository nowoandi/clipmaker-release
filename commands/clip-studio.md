Открой студийную панель проекта. $ARGUMENTS — папка проекта (иначе `$env:CLIP_PROJECT` / текущая).

```
python "${CLAUDE_PLUGIN_ROOT}/scripts/clip_studio.py" --project "<папка>" --open
```

Панель поднимается на `http://127.0.0.1:7788` и читает файлы проекта с диска: конвейер
с состоянием всех ролей, раскадровка карточками с превью кадров, таймлайн по разделам трека,
канон с якорями, снятый материал с дублями, документы и бухгалтерия. Состояние перечитывается
каждые 15 секунд — ничего не кэшируется, панель не хранит своей копии правды.

В панели можно завести новый клип: она создаст папку латиницей (R25), память проекта и бриф,
а затем выдаст команду для Claude Code. Агентов панель не запускает — это делает Директор.

Запускать в фоне (`Start-Process … -WindowStyle Hidden`, R22), чтобы не блокировать сессию;
проверка запуска — отдельным вызовом.

Панель только показывает. Вердикты по-прежнему ставятся в панели приёмки на localhost:7777
и падают в `verdicts.json` (R17); генерации запускают роли. Отсюда деньги не тратятся.

Порт занят — задать другой: `--port 7799`.

## Снимок

```
python "${CLAUDE_PLUGIN_ROOT}/scripts/clip_studio.py" --project "<папка>" --export "<папка>/output/studio.html"
```

Сохраняет тот же интерфейс одним автономным файлом: данные, превью кадров и тексты вшиты
внутрь, сервер не нужен. Годится, чтобы показать состояние Админу в чате, приложить
к паспорту клипа или оставить в архиве прогона. Видео в снимок не вшивается — только кадры,
тексты и цифры.
