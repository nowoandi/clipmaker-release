description: "Suno-hook — вертикальный ролик под фрагмент песни на suno.com: окно по треку, производство, монтаж со своим звуком, загрузка."
---

Сделай Suno-hook. $ARGUMENTS — песня (ссылка suno.com/song/… и/или путь к mp3), какой фрагмент,
идеи по планам, чей облик героини (может быть пустым).

Веди прогон по `${CLAUDE_PLUGIN_ROOT}/skills/suno-hook/SKILL.md`; ремесло — `${CLAUDE_PLUGIN_ROOT}/shared/suno/`.

1. `python "${CLAUDE_PLUGIN_ROOT}/scripts/gate_env.py"` — exit 2: сначала окружение.
2. Проект — `clip_scaffold.py --name "<название>"` (клип, 9:16), бриф в `00-brief.md`: песня с id
   версии в Suno, фрагмент, раскадровка Админа, если он её дал, границы (липсинка нет).
   Трек: если уже скачан — взять с диска и сверить длину с Suno; скачивать — только по «да».
3. Разработка до питча — агентом `clip-director` по его SKILL.md, в формате hook: окно в
   `grid.json → hook` первым делом. В питче — секунда начала фрагмента для Suno.
4. Дальше — только после явного «да» Админа: якоря → кадры → видео → приёмка → монтаж →
   `suno_pack.py` → загрузка. Подпись и «Post» — отдельное «да».
