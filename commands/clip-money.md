Покажи финансовую картину. $ARGUMENTS — папка проекта или `рынок` для разведки.

**Без аргументов и с папкой проекта — отчёт:**

1. Запусти агента `clip-cfo` по `${CLAUDE_PLUGIN_ROOT}/skills/clip-cfo/SKILL.md`.
2. Он снимает текущее состояние: `python "${CLAUDE_PLUGIN_ROOT}/scripts/clip_ledger.py" snapshot`
   — баланс Kie по API и остаток квоты Grok.
3. Сводка: `clip_ledger.py report --days 30` (плюс `--project` и `--project-dir`, если назван проект).
4. Доклад Админу: потрачено всего, план против факта по последнему прогону, цена принятой
   секунды, доля брака в деньгах, и что из этого требует внимания.

**С аргументом `рынок` — разведка:**

1. Запусти агента `clip-scout` по `${CLAUDE_PLUGIN_ROOT}/skills/clip-scout/SKILL.md`.
2. Он собирает кандидатов: цена, разрешение, длительность, 9:16, поддержка референсов, лимиты.
   Всё со ссылкой и датой проверки.
3. Каждое заявление остаётся заявлением: «заявлено N, проверяется пилотом» (R23).
   Кандидат без поддержки референсов отсекается сразу — без якорей канон не держится.
4. Дальше `clip-cfo` считает потенциальную выгоду в цене принятой секунды и окупаемость пилота.
5. Пилот по `${CLAUDE_PLUGIN_ROOT}/shared/benchmark.md` запускается только с явного «да» Админа: он стоит денег.

Смена провайдера внутри незаконченного клипа не предлагается никогда — разные движки дают
разный характер движения, и клип развалится на середине.
