# Clip Editor

## Основа

Монтаж строится от такта (R20). Данные уже сняты: сетка долей, разделы и пословные тайминги
в `clip-memory/song/grid.json` и `words.json`, длина каждого плана в долях —
в `clip-memory/script/shotlist.json`.

Ремесло — `${CLAUDE_PLUGIN_ROOT}/shared/cinema/04-editing-to-music.md`, классика склейки —
`${CLAUDE_PLUGIN_ROOT}/shared/cinema/06-classic-rules.md`.

## Правила сборки

- крупные склейки — на **сильную долю** такта; резать каждый бит нельзя, это истерика;
- ударные слова текста получают склейку точно в свою долю — для этого и нужны пословные тайминги;
- длина плана меняется по разделу: куплет длиннее, припев короче;
- второй припев плотнее первого, иначе структура песни не читается в картинке;
- только жёсткие склейки; растворения в ритмическом клипе читаются как слабость;
- брать начало клипа — там дрейф генерации минимален.

## Динамика без новых генераций

Это спасает бюджет: один источник даёт несколько планов.

- разные точки входа в один и тот же клип;
- разные крупности через кроп — внутрикадровый монтаж;
- ускорение в припеве;
- наезд по кадрам: ~0.30 в быстрых разделах, ~0.16 в медленных; направление чередуется
  между соседними планами.
- непрерывный план по пресету `oner` (R34) — готовый набор крупностей: макро, деталь,
  отъезд, орбита. Резать его на доли по стадиям, а не брать целиком;
- мелкий реквизит (монета) — поверх фона `prop_fx.py` по полю `coin_fx` сцены (R37): бросок `toss` с пальца,
  зависание `hang`, падение `fall`; текстуры лица и оборота — чистые вырезки из якорей;
- титр по варианту C (`title_reveal` без букв): надпись накладывается `drawtext` поверх
  чистой белой поверхности, текст — `vars.text` сцены, не по памяти.

## Правило шести по каждой склейке (с 0.8.35)

Админ, 14.10.2026: «шесть критериев монтажа … нам тоже нужно их интегрировать». Склейка на доле —
это один критерий из шести (ритм, 10%). Эмоция, история, взгляд, плоскость и пространство до сих пор
никто не проверял. Теперь после сборки и до отдачи:

```
python "${CLAUDE_PLUGIN_ROOT}/scripts/cut_review.py" --project "<папка>" --video "<монтаж.mp4>" --auto [--thr 0.2] [--top 12]
```

Скрипт измеряет ритм (отклонение от доли и попадание внутрь слова), прыжок яркого центра кадра и скачок
яркости, режет лист кадров вокруг каждой склейки (`output/cuts/cuts-sheet.jpg`) и пишет шаблон
`reports/cuts-review.json`. **Лист смотреть глазами**, у каждой склейки каждому из шести критериев
поставить `kept` или `sacrificed` (жертва — с причиной), потом:

```
python "${CLAUDE_PLUGIN_ROOT}/scripts/cut_review.py" --project "<папка>" --video "<монтаж.mp4>" --check
```

Жертвовать можно только снизу вверх (`shared/cinema/06-classic-rules.md`): принесён критерий выше —
нижние тоже. Склейка, где приходится жертвовать эмоцией или историей, — не склейка, а переделка:
другой план, другая точка входа, другой дубль. Замер, который спорит с твоим `kept` (ритм, взгляд), —
предупреждение: посмотри ещё раз. Длинный клип: `--top 12` разбирает самые рискованные склейки.
Мягкие склейки между похожими кадрами автопоиск пропускает — `--thr 0.2` или `--cuts` со списком.
В отчёте-фрагменте раздел «Ремесло» называет жертвы и причины.

## Четыре ffmpeg-грабли (R21)

1. zoompan без `-loop 1` на входе и `-frames:v N` — кадры множатся, длительность уезжает.
2. Не задавать timescale вручную.
3. concat разных источников — только с перекодированием, никакого `-c copy`.
4. `scale=1080:1920:force_original_aspect_ratio=increase,crop=1080:1920` — клипы Grok приходят
   разного размера (720×1264 и 704×1280 в одной пачке). Плюс `-map 0:v:0`: у клипов есть
   второй поток-обложка.

ffmpeg берётся по пути из `${CLAUDE_PLUGIN_ROOT}/config/paths.json` — в PATH его нет (R22).

Монтажный скрипт проекта пишется по образцу `edit-v2.py` из проекта <проект> —
`<new_project_root>/<проект>/edit-v2.py`. Логика — в скрипте, данные — в JSON.

## После сборки — обязательно (R18)

```
python "${CLAUDE_PLUGIN_ROOT}/scripts/gate_assembly.py" --video "<final.mp4>" --audio "<song.mp3>" --sheet
```

Логу «ГОТОВО» не верить: он писал «ГОТОВО» на четырёх багах подряд. Гейт сверяет длительность
с треком (±1 с), разрешение и режет контрольный лист из 20 кадров по всей длине.
**Лист смотреть глазами** — живёт картинка или стоит; это вторая половина R18.

## Отдача

Файл больше 30 МБ через чат не уходит — сделать сжатую копию (ffmpeg из `config/paths.json`)
и отдать её, честно пометив как сжатую. Оригинал остаётся в `output/`.

## Запрещено

- монтировать забракованное;
- перегенерировать принятое ради удобства сборки;
- подгонять длительность растяжением вместо пересчёта долей;
- отдавать результат без вывода `gate_assembly.py`.

## Черновик и монтаж — разные запуски

Черновик (аниматик до съёмки) — скрипт `draft*.py` или `animatic*.py`, выход `output/draft_*.mp4`,
в углу кадра подпись «ЧЕРНОВИК · строка · источник». Сверка роликов (R31) к нему не нужна, хук пропускает.
Окончательный монтаж — только `edit-*.py` после `gate_conformance.py`; черновой скрипт, который пишет
`final*.mp4`, хук останавливает как монтаж.
