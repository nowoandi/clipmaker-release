# Clip Frames

## Порядок

0. `clip-memory/reports/budget.json` — без вердикта `✅ OK` от директора картины генерация
   не начинается: это первый шаг прогона, который стоит денег.
1. `python "${CLAUDE_PLUGIN_ROOT}/scripts/gate_prompts.py" --project "<папка>"` — длины промптов (R05), silence-лист (R02), мусорные теги (R07), якоря (R01). Успех пишет маркер `.gates/prompts-ok.json`, а в нём список `refs_pending` — имена якорей, которых ещё нет в `canon.refs` с живым URL. **Непустой `refs_pending` — твой стоп:** гейт при этом зелёный (тексты сцен чисты, и шаг якорей им открыт), но кадры сцен хук держит, пока список не опустеет. Значит дело не в промптах, а в шаге I — звать `clip-anchors`, а не чинить данные.
2. Генератор с `--dry` — бесплатно печатает все промпты. Это последний момент, когда ошибка ничего не стоит: вычитать глазами каждый.
3. Пакет кадров. Генератор проекта — по образцу `frames-sk.js` из папки `pipeline` (путь из `${CLAUDE_PLUGIN_ROOT}/config/paths.json`).
4. Просмотр кадров, брак — точечно.

## Правки

ТОЛЬКО в project.json: текст сцены (`scene`), точечные добавки сцены (`style_override` / `neg_add`), строки канона. В скрипте-генераторе промпты не править НИКОГДА (R12: каждая правка промпта = новый файл рецепта; `gate_recipes.py` держит sha256-лок).

Переген одной сцены: `--only S07 --force` — 6 кредитов вместо перегенерации пачки.

R02: каждый дефект, замеченный при приёмке кадров, немедленно становится строкой канона (silence / must / neg) — иначе модель придумает его снова.

## Хук

PreToolUse-хук (`hook_guard.py`) блокирует запуск генератора кадров без `--dry`, если нет свежего маркера `.gates/prompts-ok.json` (живёт 4 × `preflight_ttl_min`, по умолчанию 2 часа) **или если в маркере непустой `refs_pending`** — тогда сообщение про R01, а не про R05. Блокировка — не сбой, а R05/R08 в коде: прогнать `gate_prompts.py`, починить данные — запуск откроется.

Имя генератора хук узнаёт по шаблону `frames-<что угодно>.js`, а не по списку из трёх имён: копия под проект (`frames-sandy.js`, R32) обязана попадать под то же правило. Переименованием команд блокировку не обходить — ровно так 18.09.2026 якорь сняли через `anchor.js`, которого хук тогда не видел.
