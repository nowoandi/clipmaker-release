# Контракт рекламного шот-листа

Файл `clip-memory/script/shotlist.json`, `form: "ad"`. Проверяет его `gate_ad_script.py`.
Клип устроен иначе (`shared/shotlist-contract.md`): там длину планов задаёт сетка такта, здесь —
секунды ролика. Общее у них — словарь, якоря, источники для сверки (R31) и принцип «чинится
шот-лист, а не скрипт».

## Верхний уровень

```json
{
  "form": "ad",
  "format": "ad",
  "duration_sec": 8,
  "change": "от пустого стола к вещи, которую хочется взять",
  "product_anchor": "product",
  "shots": [ ... ],
  "sources": { "N01": { "desc": "сумка на светлой плите, общий план" } }
}
```

| Поле | Обязательно | Смысл |
|---|---|---|
| `form` | да | ровно `ad` (клипы — `gate_script.py`) |
| `format` | да | `card` или `ad`; **паспорт товара главный**: расхождение с `product.json` — отказ |
| `duration_sec` | да | длительность ролика, положительное число; сумма `sec` обязана сойтись ±0,5 с |
| `change` | для `ad` | что меняется от первого кадра к последнему; без перемены это витрина (для неё есть `card`) |
| `product_anchor` | нет | имя якоря товара; по умолчанию `product` |
| `shots` | да | `card` — 2–6 планов, `ad` — 3–7 |
| `sources` | если есть `src` | `src → { "desc": "..." }`, подпись на контактном листе приёмки (R31) |

## Кадр

```json
{
  "id": "S02",
  "act": "turn",
  "sec": 2.0,
  "size": "MS",
  "angle": "eye",
  "movement": "push_in_slow",
  "anchors": ["product"],
  "product_visible": true,
  "src": "N02",
  "in": 0,
  "content": "the bag on a pale stone slab, brass clasp catches the light",
  "light": "soft window light from the left, deep shadow on the right",
  "note": "крючок: пряжка ловит свет — зритель впервые видит вещь"
}
```

| Поле | Обязательно | Смысл |
|---|---|---|
| `id` | да | `S01`, `S02`… |
| `act` | для `ad` | `intro`, `turn`, `main`, `outro` — акты (`cinema/08-dramaturgy-short-form.md`) |
| `sec` | да | длина плана **в секундах**, число > 0 |
| `size`, `angle`, `movement` | да | словарь как у клипа (`gate_script.py`) |
| `anchors` | да | имена якорей; пусто допустимо только с `"anchors_free": true` |
| `product_visible` | да | товар в кадре. Если `true`, в `anchors` обязан быть якорь товара — форму и цвет вещи держит картинка, не слова (R01) |
| `src`, `in` | `src` — у всех или ни у кого | источник кадра `clips/<src>.mp4`; `in` — с какой секунды исходного клипа брать (по умолчанию 0) |
| `content`, `light` | да | по-английски: их читает промптер и модель |
| `note` | да | зачем кадр здесь, по-русски |

## Что проверяет `gate_ad_script.py`

**Отказ (exit 2):**

1. `form` = `ad`; `format` из списка и совпадает с паспортом; `duration_sec` число.
2. Число планов в пределах формата.
3. Словарь `size` / `angle` / `movement`; `sec` > 0.
4. Якоря существуют (`canon.refs` или `anchor-brief.json`).
5. У каждого кадра с товаром есть якорь товара.
6. Полнота: `content`, `light`, `note`.
7. Источники: `src` у всех или ни у кого; каждый описан в `sources` с непустым `desc`.
8. Сумма `sec` сходится с `duration_sec` ±0,5 с.
9. Хотя бы в одном кадре виден товар.
10. Для `ad`: у каждого кадра верный `act`; первый — `intro`, последний — `outro`; **в последнем кадре есть товар**.
11. У соседних кадров не совпадают одновременно `size` и `movement`.

**Предупреждение (печатается `[~]`, маркер пишется):**

- `card`: товар виден меньше чем в 80% кадров;
- `ad`: нет кадра с `act=turn` — события, которое выталкивает из первого акта во второй;
- `ad`: развязка (`outro`) длиннее 5 секунд — наблюдение, не проверено нашим прогоном;
- одинаковая крупность через один (A–B–A). У клипа на 89 планов оно срабатывало в 30% троек и было
  шумом, поэтому там не проверяется; на 3–7 кадрах это обычный сигнал вялой раскадровки.

**Чего нет и почему:** центра внимания соседних кадров. Правило «совпал или сдвинут на треть»
проверяемо, но поля `focus` в шот-листе нет, а пилот на живом шот-листе
не прогнан (`shared/ads/02-plan.md`).

## Маркеры

Успех пишет `.gates/script-ok.json` и `.gates/density-ok.json` с `kind: "ad"`. Второй — потому
что хук требует его на генерацию якоря и кадров, а плотность визуала против энергии трека у
рекламы считать нечем: трека нет. Здесь маркер значит лишь «структура ролика проверена».

## Как промптер читает строку

Так же, как у клипа (`shared/shotlist-contract.md`, «Как из строки собирается промпт»), с двумя
отличиями: длина плана берётся из `sec`, а не из `beats`, и для кадров с `product_visible: true`
форму товара держит якорь, поэтому слова о ней в промпт не идут (R01, R02). Всё, что якорь не
держит (свет, крупность, движение, окружение), пишется словами.
