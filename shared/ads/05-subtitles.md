# Субтитры: слой оформления для клипа, рилса и рекламы

Админ, 18.10.2026: «Субтитры — очень классная штука, особенно когда лежишь вечером и включил видео не
для того, чтобы смотреть, а практически прочитать». Ролик с субтитрами читается без звука и без внимания к
картинке. Делает слой `scripts/subtitles.py` (0.8.36). Платных сервисов не нужно: тайминги слов дал
faster-whisper локально (`clip-memory/song/words.json`, `RULES.md`, раздел про транскрипцию).

## Включаются платформой (0.8.37)

Админ, 18.10.2026: субтитры для Suno не нужны, а для Инстаграма и прочего — нужны; пусть включаются в зависимости
от платформы, достаточно указать, для чего делаем. Для этого есть поле **`platform` в `project.json`** и профили в
`config/platforms.json`:

| Платформа | Субтитры | Кадр | Безопасная зона снизу |
|---|---|---|---|
| `suno-hook` | **запрещены** | 9:16 | 30 % |
| `instagram-reels`, `tiktok`, `youtube-shorts`, `vk-clips`, `generic-vertical` | рекомендуются | 9:16 | 30 % |
| `youtube-long` | выключены по умолчанию, не запрещены | 16:9 | 8 % |
| `ads-ozon-wb` | рекомендуются | 3:4 | 10 % (ориентир без источников) |

Задаётся при заведении: `clip_scaffold.py --name … --platform instagram-reels` (клип без ключа получает
`generic-vertical`, с `--hook` — `suno-hook`, реклама — `ads-ozon-wb`). Менять у существующего проекта — тем же
скаффолдом с явным `--platform` или правкой поля руками. **Нет поля — старое поведение:** ничего не включается и не
запрещается, а hook узнаётся по `grid.json`. Сменить платформу на один запуск: `subtitles.py --platform tiktok`.
Явная платформа не-Suno главнее окна hook в `grid.json`; файл `*-suno*.mp4` отказывает при любой платформе.
`clip_status.py` показывает «субтитры: включены/выключены/ЗАПРЕЩЕНЫ для платформы X». В конвейере шаг стоит после монтажа
и до упаковки и не блокирует.

Числа профилей, кроме кадра и длины Suno-hook (экран загрузки 13.10.2026), — **ориентир, сверить с площадкой**; у
каждого профиля в `provenance` написано, откуда число. Длины Reels, TikTok, Shorts, VK менялись и могут поменяться.

## Где субтитры НЕ нужны

**Suno-hook.** Букв в кадре быть не должно: Suno сам показывает текст песни (Админ, 18.10.2026).
`subtitles.py` на проекте с окном hook (`grid.json → hook.start/end`), с паспортом `publish/suno-hook.json`
или на файле `*-suno*.mp4` выжигание отказывает с кодом 2. Файлы SRT/ASS отдаются с предупреждением
«не вшивать». См. `shared/suno/00-README.md`, `05-safe-zone.md`.

## Команды

```
python scripts/subtitles.py --project <клип>                       # показать фразы, ничего не писать
python scripts/subtitles.py --project <клип> --srt o.srt --ass o.ass [--karaoke]
python scripts/subtitles.py --project <клип> --burn output/final.mp4 --out output/final-sub.mp4 [--karaoke]
python scripts/subtitles.py --project <клип> --lyrics --burn ... --out ...   # текст автора
python scripts/subtitles.py --check-fonts
```

`--start/--end` — окно трека (секунды): слова берутся из него и сдвигаются к нулю ролика, если ролик собран
из куска трека. Путь к ffmpeg — из `config/paths.json` (R22), как у остальных скриптов.

## Как собираются фразы

Из пословных таймингов (`word`, `start`, `end`; формат — список или `{"words": [...]}`):

1. Фраза закрывается на паузе ≥ 0,5 с, на конце предложения (`. ! ? …`), на запятой при двух и более словах,
   на переполнении 40 знаков и — для русского и английского — на слове с большой буквы (whisper пишет
   строки песен с большой). **В немецком этот признак выключен:** там с большой пишутся все существительные.
2. Осколки («я», «и», фраза короче 0,35 с) клеются к соседней, если помещаются и пауза мала.
3. Фраза держится 0,12 с после последнего слова, но не налезает на следующую (зазор 0,02 с).
4. Строка переносится пополам по знакам, не больше двух строк. Размер строки считается от ширины кадра.

Пороги — ориентир, не измерены нами на реальных роликах (R23). Первый прогон на живом материале покажет,
какие подкрутить; значения лежат в начале `subtitles.py`.

## Текст автора: `--lyrics`

По R33 источник слов — авторский текст, источник таймингов — машина. Режим читает `clip-memory/song/lyrics-author.md`
(тексты до строки `---` и теги `[Verse]` отбрасываются), привязывает строки к словам whisper выравниванием по
сходству (слово, которое whisper услышал неточно, — «живаю» вместо «оживаю» — всё равно встаёт на место) и
показывает **строки автора**, каждая строка — одна фраза. Строки без слов в тайминге (вне окна, служебные)
выпадают и перечисляются в выводе. Слово без пары внутри строки получает время интерполяцией.

## Караоке

`--karaoke` — ASS с меткой `\k` на каждое слово: слово подсвечивается жёлтым, когда его поют. Подсветка
держится до начала следующего слова. Для рекламы с речью и для песен; для обычных подписей хватает белого.

## Безопасная зона и размер

Низ текста — на 30 % высоты выше нижней кромки для вертикали (1344 px при 1920), на 8 % для горизонтали;
поля 90 px при ширине 1080. Шрифт жирный, обводка чёрная, размер 64 px при ширине 1080. Числа — ориентир из
сторонних обзоров, не наш замер: `shared/suno/05-safe-zone.md`. Менять: `--bottom-safe`, `--font-size`.

## Шрифт: проверяется явно

Провал шрифта не даёт ошибки — ffmpeg молча берёт чужой или рисует квадраты. Поэтому скрипт сам ищет шрифт
из списка Windows (Segoe UI, Arial, Tahoma, Verdana, Trebuchet MS, Calibri, Impact), проверяет, что в нём есть
русские буквы с ё, й, ъ, ы, э, ю, немецкие ä ö ü Ä Ö Ü ß и типографские знаки (если стоит `fontTools`), и копирует
его в рабочую папку выжигания. Не нашёл — **отказ**, а не подмена. Свой файл: `--font-file путь.ttf`.
Проверка без записи: `--check-fonts`.

## Что проверено и чего нет

Проверено самотестом (`gate_selbsttest.py`): группировка, SRT и ASS, караоке, привязка текста автора,
отказ без шрифта, отказ на hook, выжигание ffmpeg (текст есть в средней части кадра и нет в нижних 30 %).
**Не проверено:** как субтитры выглядят на реальном ролике на экране телефона; скорость чтения (знаков в
секунду) на быстрых песнях; поведение libass на чужом ffmpeg без fontconfig; работа на немецкой песне.
Первый живой прогон — смотреть глазами и записать замечания сюда.
