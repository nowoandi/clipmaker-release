# Рекламная ветка ClipMaker — товар, а не песня

Второй продукт студии: **короткий рекламный ролик и карточка товара для маркетплейса**.
5–15 секунд, 3–5 планов, кадр 3:4. Заведена 10.10.2026 по решению Админа: «кроме клипов
к музыке будет новый навык, совсем новый».

Это не разновидность клипа. Совпадает машина (деньги, гейты, приёмка), расходится ремесло.

## Чем отличается от музыкального клипа

| | Клип | Рекламный ролик |
|---|---|---|
| Ритм задаёт | трек: сетка долей, такты, разделы | драматургия показа; трека может не быть вовсе |
| Герой | придуман, канон решает студия | **реальный товар**, канон задан вещью на складе |
| Границы правды | факт-банк темы | закон о рекламе и правила площадки |
| Длина | 3–4 мин, 20–40 планов | 5–15 с, 3–5 планов |
| Что значит «принято» | нравится | товар **узнаётся** и совпадает с карточкой |
| Главный якорь | лицо и костюм героини | форма, цвет, фурнитура, логотип товара |
| Формат кадра | 9:16 | 3:4 (карточки WB и Ozon), квадрат допустим; 9:16 только для ленты |

Отсюда главное следствие: **в клипе брак по якорю стоит денег, в рекламе он стоит доверия.**
Героиня с чуть другим лицом — плохой клип. Сумка с чуть другой фурнитурой — товар, которого
покупатель не получит.

## Что переносится из клипа без изменений

Вся денежная и приёмочная машина: хук-гейт (R08), предполёт, смета (R29), реестр
скачанного (R14, R30), сверка со сценой (R31), якорный принцип (R01, R03, R04),
разделение шага якорей и шага кадров (03.10.2026).

Роли клипа, которые реклама берёт как есть (с абзацем «Рекламный проект» в скилле): `clip-anchors`,
`clip-frames`, `clip-shoot`, `clip-guardian`, `clip-line-producer`, `clip-production-designer`,
`clip-dop`, `clip-prompt-writer`. Не берёт: `clip-researcher`, `clip-musicologist`,
`clip-screenwriter` (ему на смену — `ad-storyboard`), `clip-editor` (по сетке такта; вместо него
`ad_assemble.py` по секундам).

## Чего в клипе нет — и что завели (версия 1, 0.8.18)

1. **Приёмка товара** — паспорт `clip-memory/product/product.json` и гейт `gate_product.py`: реальные
   фото, что обязано совпасть, чего нельзя обещать, площадка, оффер, формат кадра (3:4 по умолчанию). Без этого якорь не из чего делать.
2. **Оффер** — поле паспорта: слоган, крючок первых секунд, выгода, призыв. Для `ad` слоган и крючок
   обязательны. Именно слоганом Админ хочет вызывать навык; слоган сам по себе ветку не вызывает —
   вызывают слова «рекламный ролик», «карточка товара» и команда `/clipmaker:ad-new`.
3. **Требования площадки** — в паспорте площадка названа, **правил за ней нет** (в изученном про
   маркетплейсы ничего не сказано); замерить на тестовом кадре. Формат кадра решён отдельно: 3:4,
   поле `aspect` паспорта (`04-hooks.md`, «Формат кадра»).
4. **Драматургия короткого** вместо сетки такта — роль `ad-storyboard`, рекламный шот-лист в секундах,
   гейт `gate_ad_script.py`.
5. **Сборка по секундам** вместо сетки такта — `ad_assemble.py`.

## Слой оформления: субтитры (0.8.36)

Субтитры рекламе нужны: ролик смотрят без звука. Делает `scripts/subtitles.py`, правила — `05-subtitles.md`. Логотип, плашки и звук по-прежнему не сделаны.

## Статус

Ветка собрана до приёмки и сборки и проверена на синтетических данных. **Ни один реальный товар через
платную часть не проходил.** Ремесло собрано из открытых источников и **не проверено нашим прогоном**
(R23): это гипотезы, а что сработало и что нет — пишется там, где лежит правило, строкой с числом; как разбирать источники — `01-sources.md`.
Что построено, что отложено и почему — `02-plan.md`. Что измерено про крючок первых секунд и чего
нет — `04-hooks.md`.
