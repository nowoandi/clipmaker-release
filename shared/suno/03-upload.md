# Загрузка на suno.com

Проверено 13.10.2026 в Chrome Админа (Claude in Chrome, его вход в Suno). Интерфейс Suno
меняется — сверять с экраном, а не с этим текстом.

## До браузера

```
python "${CLAUDE_PLUGIN_ROOT}/scripts/suno_pack.py" --project <клип> --master output/<монтаж>.mp4 \
       --song-url https://suno.com/song/<id> [--fade-from <сек трека>]
```

Скрипт проверяет 9:16, 10 с – 4 мин, длину ролика против окна, вшивает окно трека вместо
звука модели и делает копию под загрузку не тяжелее 9,5 МБ: инструмент загрузки Chrome
берёт до 10 МБ, а мастер на 22 с весит около 20 МБ. Паспорт — `publish/suno-hook.json`,
`status: ready`.

## В Suno

1. `suno.com/hooks/create` → окно «Create a New Hook / Select Song».
2. Поиск по названию. Версий одной песни бывает несколько (у «Delta» их три:
   3:30, 3:39, 3:41) — выбирать ту, чей `href` содержит id из `--song-url`, и жать её «Use».
3. «Upload a Video» → файл `upload_file` из паспорта. Кнопку не нажимать: инструмент
   загрузки работает по ссылке на `input type=file`, а нажатие открывает системное окно.
4. Справа «Audio Controls» → **Video sound** включить, **Song sound** выключится сам
   («Only one audio source can play at a time»). Дорожка песни под роликом исчезнет — так и надо.
   - **Начало окна ставить ДО этого, при «Song sound»** (проверено 21.10.2026): при «Video sound» волна
     песни и рамка окна скрыты вовсе. После загрузки видео «Song sound» включён сам: тянуть волну внутри
     рамки (рамка стоит, волна едет), сдвиг в пикселях ≈ секунды × ширина рамки / длина ролика (у 14,6 с
     ≈ 23 px/с, 367 px = 16 с). Метка над рамкой показывает только мин:сек; точное время — подсказка при
     наведении на ЛЕВЫЙ край рамки, три знака («4:03.990» при цели 244,00). Потом «Video sound» обратно.
   - В «Select Song» у песни бывает много версий с одним названием (у «Весь мир танцует» — десять, пять
     из них [Remix] и [Tech House]): «Use» жать у строки, чья ссылка содержит нужный id
     (`a[href*="/song/<id>"]` → ближайший предок с «Use»).
5. «Next» → окно «Post Hook»: подпись, «Allow comments», «Show Lyrics», «Pick Cover Frame».
   - **«Pick Cover Frame» — открыть всегда.** Suno по умолчанию кадр обложки выбирает сам и это не
     первый кадр: у «Am Morgen» (14.10.2026) в превью стоял поздний кадр с касанием щёк. Выбрать
     нужный (по правилу — первый, крайний левый в ленте), «Save» и сверить превью в «Post Hook»:
     обложку после публикации не поменять.
   - Подпись — одной строкой: переносы строк Suno съедает, и хэштег прилипает к слову.
   - Что видео сделано с помощью ИИ — писать прямо (Админ, 13.10.2026: «тут можно спокойно
     написать, что с помощью искусственного интеллекта видео»).
   - «Show Lyrics» при звуке из видео — выключен: текст идёт по таймингам песни.
6. **«Post» — только после «да» Админа на подпись.** Это публичная публикация.
   - После «Post» в адресной строке сначала чужой хук из ленты («Uploading your hook…», «Cancel» не нажимать
     и страницу не менять), секунд через 10–15 страница сменяется на свою. Настоящую ссылку брать в
     «Library → Hooks» (`suno.com/me/hooks`, первая карточка, `a[href*="/hook/"]`).
7. Ссылка на hook (`suno.com/@<автор>/hook/<id>`) и подпись — в `publish/suno-hook.json`, `url` и
   `caption`, `status: posted`. С этого момента `suno_pack.py` паспорт не перезапишет.

## Что правится после публикации (замерено 14.10.2026)

Библиотека → «Hooks» (`suno.com/me/hooks`) → «⋮» у карточки: «Edit» и «Delete». В «Edit Hook» правятся
только подпись, «Allow comments» и «Show Lyrics». Кадр обложки и само видео — нет. Значит, плохой первый
кадр или плохой монтаж лечатся только новым hook'ом. У каждого hook'а свои просмотры и лайки (они
видны на карточке), поэтому при удалении и повторной загрузке они начинаются с нуля. Лайки самой песни
отдельные. «Delete» без «да» Админа не нажимать.

## Чего не делать

- не нажимать «Post», пока не прочитана подпись в поле (`zoom` по полю): ввод через `type`
  теряет переносы;
- не выбирать «Song sound» для ролика с монтажом под окно — шаг ползунка Suno даёт сдвиг;
- не закрывать чужие вкладки Suno: работать в своей и закрыть её в конце.
