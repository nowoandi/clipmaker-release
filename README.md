# ClipMaker

> **RU** · [English below](#english)

**ClipMaker** — студия музыкальных AI-клипов, плагин для Claude Code. Вы называете песню и тему — студия
изучает тему, пишет сценарий, раскладывает раскадровку по такту, считает смету и приносит **решение**.
После вашего «да» снимает и монтирует.

- Студия специализированных ролей — ресёрчер, сценарист, художник-постановщик, оператор, раскадровщик,
  промпт-инженер, монтажёр, приёмка, финансовый директор, доктор; вход — команды вроде `/clipmaker:clip-new`.
- Правила живут в коде, а не в пересказе: гейты — скрипты, которые бросают исключение; хук блокирует
  генерацию без шот-листа, съёмку без предполёта и монтаж без сверки со сценой.
- Три ветки: музыкальный клип, короткий рекламный ролик для товара, Suno-hook (вертикальное видео 9:16
  под фрагмент песни на suno.com).
- Монтаж от сетки такта (ffmpeg), кадры через Kie, движение через Grok.

**Нужно:** Windows 10/11, Claude Code с плагинами, Python 3, ffmpeg.

**Не входит в плагин:** мост Grok, pipeline-v3 (генераторы кадров и якорей через Kie) и ключ Kie. Бесплатная
часть — тема, сценарий, раскадровка, смета, проверки гейтами — работает сразу после установки. Кадры и видео
платные и нужны эти внешние части.

**Лицензия:** MIT. Имена проектов в примерах и пояснениях заменены на Alpha, Bravo, Charlie, Delta.
Установка — раздел «Установка» ниже. Подробная документация ниже, на русском.
**«Админ»** в текстах ролей — это вы, владелец студии: тот, кто принимает решения и говорит «да» перед платными шагами.

## English

**ClipMaker** is a Claude Code plugin that works as an AI music-video studio. You give it a song and a theme.
The studio researches the theme, writes the treatment, lays out a beat-grid storyboard, estimates the cost and
brings you a decision. After one "yes" it shoots and edits.

- A studio of specialist roles — researcher, screenwriter, production designer, DoP, storyboard artist, prompt
  writer, editor, guardian, financial director, doctor — driven by slash commands such as `/clipmaker:clip-new`.
- Rules live in code, not in prose: gates are scripts that raise errors, and a PreToolUse hook blocks
  generation without a shot list, shooting without a preflight check, and assembly without a scene check.
- Three branches: music clip, short product ad, and Suno hook (a vertical 9:16 video for a fragment of a song
  on suno.com).
- Beat-grid montage with ffmpeg, frames through Kie, motion through Grok.

**Requirements:** Windows 10/11, Claude Code with plugin support, Python 3, ffmpeg.

**Not included:** the Grok bridge, pipeline-v3 (frame and anchor generators via Kie) and a Kie API key. The free
part — theme, script, storyboard, cost estimate, gate checks — works right after installation. Generating frames
and video costs credits and needs those external parts.

**Install**

```text
/plugin marketplace add nowoandi/clipmaker-release
/plugin install clipmaker@clipmaker
```

**First run:** copy `config/paths.json` outside the plugin, put your own paths into the copy, and point the
`CLIPMAKER_CONFIG` environment variable at it, so plugin updates do not overwrite your settings.

**Language and license:** the prompts, rules, knowledge base and the documentation below are written in
Russian. MIT license. Project names in examples and explanations are replaced with Alpha, Bravo, Charlie, Delta.
In the role prompts, "Админ" ("Admin") means you: the studio owner who approves decisions and says "yes" before any paid step.

# Документация (на русском)

**Вторая ветка — короткий рекламный ролик и карточка товара** (с версии 0.8.18). Это не клип:
она начинается с вещи и её фото, а не с песни. Слова «рекламный ролик», «ролик для товара»,
«карточка товара», «вставка для маркетплейса» ведут сюда — `/clipmaker:ad-new`, директор `ad-director`.
Машина общая (хук, смета, якоря, приёмка), ремесло своё: `shared/ads/`. Версия 1 собрана и проверена
на синтетических данных; пилот на реальном товаре ещё не прогнан, правил площадок в ней нет.

**Третья ветка — Suno-hook** (с версии 0.8.27): вертикальный ролик 9:16 под фрагмент песни на
suno.com. Окно фрагмента считается по треку до загрузки, производство — общий конвейер в формате
hook, звук трека вшивается в ролик, в Suno выбирается «Video sound». Вход — `/clipmaker:suno-hook`,
навык `suno-hook`, ремесло `shared/suno/`, упаковка `scripts/suno_pack.py`. Отработана на живом
прогоне «Delta» (13.10.2026).

**Правило шести** (Уолтер Марч, с версии 0.8.35). Склейка монтажа проверяется по шести критериям — эмоция,
история, ритм, взгляд, плоскость, пространство: `scripts/cut_review.py` измеряет ритм, прыжок взгляда и
скачок яркости, режет лист кадров, глаз выносит вердикт, скрипт проверяет, что жертвуют снизу вверх.
Hook без такого разбора в Suno не уходит.

**Слой оформления и замеры** (с версии 0.8.36). `scripts/subtitles.py` собирает из пословных таймингов
`words.json` (faster-whisper, локально, бесплатно) читаемые фразы, пишет SRT и ASS (караоке-подсветка слов по
желанию), выжигает их ffmpeg с учётом безопасной зоны кадра и проверяет, что шрифт с кириллицей и умляутами есть;
режим `--lyrics` показывает текст автора с привязкой к таймингам. **В Suno-hook букв в кадре быть не должно** —
Suno сам показывает текст песни, поэтому на проекте с окном hook выжигание отказывает. Рядом: громкость итога
`suno_pack.py` (LUFS и истинный пик, только предупреждение), `gate_slideshow.py` (риск «слайдшоу» шот-листа,
предупреждение), журнал решений о провайдере (`clip-memory/reports/decisions.jsonl`), коды дефектов и критик-разгром
в `clip-guardian`, таблица причин дефектов `shared/cinema/13`. Подробно — `shared/ads/05-subtitles.md`,
`shared/suno/05-safe-zone.md`.

**Платформа: «для чего делаем»** (с версии 0.8.37). Поле `platform` в `project.json` (`clip_scaffold.py --platform`,
`--hook` для Suno-hook) выбирает профиль из `config/platforms.json`: `suno-hook`, `instagram-reels`, `tiktok`,
`youtube-shorts`, `youtube-long`, `vk-clips`, `ads-ozon-wb`, `generic-vertical`. Профиль задаёт кадр, длину, безопасную
зону, ориентир громкости и главное — **субтитры**: у `suno-hook` они запрещены, у остальных разрешены или рекомендованы.
Субтитры включаются и выключаются платформой, а не вручную (Админ, 18.10.2026). `clip_status.py` показывает
«субтитры: включены/выключены для платформы X». Нет поля — старое поведение. Числа профилей, кроме проверенных
(кадр и длина Suno-hook), — ориентир, сверить с площадкой.

**Глаз оператора и полка движений** (с версии 0.8.28). Оператор пишет в `camera.json → checks`, что
должно быть видно на кадре (свет, камера, цвет, физика, люди); clip-guardian сверяет с этим каждый
кадр ДО видео (`gate_frames.py`, `reports/frames-review.json`), и предполёт без принятого разбора
партию не пускает. Движения — с полки `shared/motion-refs/`: раскадровка по долям секунды и карточка
«как это бывает в жизни» (`scripts/motion_ref.py`); физика и близость пары — `shared/cinema/10`, `11`.

Правила, оплаченные квотой и ночами отладки, живут в коде: гейт-скрипт бросает исключение,
PreToolUse-хук физически не даёт запустить генерацию в обход порядка. Ремесло — язык кадра,
монтаж под музыку, классика склейки — лежит в базе знаний и читается ролями, а не
объясняется каждый раз заново.

## Как это работает

```
/clip-new "песня.mp3, клип про ..."

ресёрч темы ‖ разбор трека  →  сценарий  →  канон (мир ‖ камера)  →  раскадровка  →  промпты
                                                                                      ↓
                                                                              ПИТЧ АДМИНУ
                                                                        концепция, раскадровка, смета
                                                                                      ↓ «да»
                                смета → якоря → кадры → съёмка → приёмка → монтаж → паспорт → доктор
```

До питча всё бесплатно. После питча каждый шаг стоит кредитов Kie или процентов квоты Grok.

## Команды

| Команда | Что делает |
|---|---|
| `/clipmaker:clip-new` | Новый клип: тема и трек → разработка → питч → производство |
| `/clipmaker:clip-continue` | Продолжить прерванный прогон с точного места, без перегенерации оплаченного |
| `/clipmaker:ad-new` | Новый рекламный ролик или карточка товара: фото и паспорт → разработка → питч → производство |
| `/clipmaker:ad-continue` | Продолжить прерванный рекламный прогон с точного места |

| `/clipmaker:clip-status` | Состояние с диска и следующий шаг. Всегда после перерыва или сжатия контекста |
| `/clipmaker:clip-shoot` | Партия съёмки: предполёт → 4–5 отправок → доклад |
| `/clipmaker:clip-assemble` | Сборка по сетке такта → `gate_assembly` с листом кадров |
| `/clipmaker:clip-doctor` | Ретроспектива прогона; `apply <ID>` — применить патч вручную |

## Студийная панель

```
/clipmaker:clip-studio            →  http://127.0.0.1:7788
STUDIO.bat                        ←  двойной щелчок, без Claude Code
```

`STUDIO.bat` в корне плагина — точка входа для человека: находит проекты клипов
(`project_roots` в `config/paths.json`) и открывает тот, с которым работали в прошлый раз —
студия помнит последний проект в `%LOCALAPPDATA%\ClipMaker\state.json`. Список показывается,
если памяти ещё нет или запуск идёт с ключом `--pick`; сменить проект можно и в самой панели.
Новый клип кладётся в `new_project_root`, а не внутрь соседнего проекта. Ярлык на него кладётся на рабочий стол. Окно = работающая
студия: закрыл окно — остановил панель, забытых процессов на портах не остаётся.

Панель открывает и проекты старого образца — без `clip-memory` и шот-листа: тогда кадры
берутся из `scenes[]` в `project.json`, длина показывается в секундах, разделы — по блокам.

Весь проект в одном окне, без поиска по файлам: обзор с этапами и гейтами, **конвейер**
с состоянием всех восемнадцати ролей, раскадровка карточками с превью кадров и таймлайном
по разделам трека, канон с якорями (зелёным — что якорь держит, жёлтым — что не держит),
снятый материал с дублями и вердиктами, документы проекта и бухгалтерия.

**Конвейер** показывает, кто из ролей отработал и кто следующий. Статус берётся из фрагмента,
который роль пишет сама по `shared/decision-contract.md` — панель не гадает и не пересказывает,
а читает ту же строку «Статус», что и директор.

**Новый клип заводится прямо в панели**: раздел «＋ Новый клип» — название, тема, трек,
ограничения, референсы. Панель создаёт папку латиницей (R25), память проекта по протоколу
и `00-brief.md`, после чего выдаёт готовую команду для Claude Code. Сама она агентов
не запускает и денег не тратит: работу ведут роли.

Проект переключается щелчком по названию в левом верхнем углу.

Панель читает файлы с диска и перечитывает их каждые 15 секунд. Своей копии правды у неё
нет, поэтому она не может разойтись с тем, что видят роли. Файлы отдаются только изнутри
папки проекта.

Панель **только показывает**: вердикты по-прежнему ставятся в панели приёмки на localhost:7777
и падают в `verdicts.json` (R17), генерации запускают роли. Отсюда ничего не тратится.

Вид — тёмная аппаратная: графит, сигнальные индикаторы состояния, DIN-типографика приборных
панелей и моноширинные тайм-коды. Шрифты только системные, никаких внешних ресурсов —
панель обязана открываться без интернета.

`--export <файл>` сохраняет тот же интерфейс одним автономным файлом (данные и превью внутри):
показать состояние в чате, приложить к паспорту клипа, оставить в архиве прогона.

## Два языка

Разделение простое и проверяется кодом (R25, `gate_lang.py`):

**Латиницей** — всё, что читает машина: имена файлов и папок, идентификаторы кадров, имена
якорей и разделов, значения словарей, и всё, что уходит в модель — промпты сцен, движение,
стиль, негатив, silence. Плюс `.bat`: cmd читает их в OEM-кодировке.

**По-русски** — всё, что читает человек: тритмент, досье, экспликация, `note` кадра,
`why` якоря, риски оператора, вердикты, отчёты, паспорт, handoff. Гейт этого не касается —
обеднять описание процесса незачем.

Новый проект заводится с латинским именем папки: «Рубка связи» → `rubka-svyazi`.

## Деньги

Смету одного прогона считает директор картины и держит гейт перед первой платной генерацией.
Накопительную бухгалтерию ведёт финансовый директор: `scripts/clip_ledger.py` снимает баланс
Kie по API и остаток квоты Grok, фиксирует расход каждого этапа на диск
(`%LOCALAPPDATA%\ClipMaker\ledger.jsonl`, вне репозитория) и считает **цену принятой
секунды** — единственную величину, которую можно сравнивать между проектами.

Разведчик рынка приносит кандидатов на замену, но слова «дешевле» и «лучше» не произносятся
без своего замера: любой кандидат проходит одинаковый пилот из трёх сцен по
`shared/benchmark.md`, и только после него считается окупаемость (R23, R24).

## Три слоя, на которых всё держится

**Данные.** Всё про проект — канон, якоря, сцены, сетка такта, статусы — в файлах на диске.
После сжатия контекста роль перечитывает файл и продолжает с точного места.

**Гейты.** Каждое машинно-проверяемое правило — скрипт, который бросает исключение.
`gate_research` не пускает сценариста без фактуры, `gate_script` не пускает промптера без
сходящегося шот-листа, `gate_prompts` ловит длину и мусорные теги, `gate_preflight` держит
квоту моста или, для видео через Kie, потолок сметы и баланс, `gate_conformance` не даёт принять чужую сцену, `gate_assembly` не верит логу «ГОТОВО».

**Хук.** PreToolUse блокирует запуск: генерация кадров без шот-листа и без проверки промптов,
съёмка без предполёта, монтаж без сверки роликов со сценой. Модель не может это обойти,
в каком бы состоянии ни был её контекст.

## Установка

```text
/plugin marketplace add nowoandi/clipmaker-release
/plugin install clipmaker@clipmaker
```

Если репозиторий приватный, владелец должен добавить ваш аккаунт GitHub в соавторы, а на машине нужен вход в GitHub (`gh auth login`).

**Первый запуск: пути вашей машины.** `config/paths.json` в репозитории — шаблон с условными путями (`C:\ClipMaker\...`). Свои пути (ffmpeg, мост Grok, pipeline, корень проектов) не правьте в самом плагине: скопируйте файл за его пределы, впишите свои и задайте переменную `CLIPMAKER_CONFIG` на копию — обновление плагина её не затронет.

Переменная `$env:CLIP_PROJECT` — папка текущего проекта; её читают хук и все скрипты
(приоритет: `--project` > `CLIP_PROJECT` > cwd). Хук сверх того смотрит, куда команда
переходит сама (`cd`, `Set-Location` — раньше `CLIP_PROJECT`), поднимается от cwd к
родителям и в конце ищет путь внутрь клипа в тексте команды. Не нашёл клип, а cwd или
команда — в корне клипов, `pipeline` или `grok_bridge`, — запуск стоит (с 0.8.25).

## Связь с внешними частями

| Что | Ключ в `config/paths.json` |
|---|---|
| мост Grok: съёмка, квота, панель приёмки на localhost:7777 | `grok_bridge`, `review_panel_bat` |
| pipeline-v3: генераторы кадров и якорей, загрузка | `pipeline` |
| ffmpeg (в PATH его нет — R22) | `ffmpeg` |

Пути правятся только в `config/paths.json`: ни скиллы, ни агенты путей машины не знают.
